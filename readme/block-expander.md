# Раскрыватель блока

`UC\BlockExpander` и плагин `block-expander` (`project/web/assets/plugins/block-expander`). Имя есть в `project/config/plugins.php`, загрузчик не ищет его в ядре. Кнопка стоит по центру нижней границы своего контейнера и показывает или прячет один подблок внутри него.

## Как вставить

```php
<?= \UC\BlockExpander::open([
    'more' => 'Больше фильтров',
    'less' => 'Меньше фильтров',
]) ?>
    …видимая часть…
    <div data-block-expander-more>…скрытая часть…</div>
<?= \UC\BlockExpander::close() ?>
```

`more` и `less` — подписи закрытого и открытого состояния. Пустое значение заменяется на «Больше» и «Меньше». `open => true` открывает подблок сразу.

Плагин сам добавляет кнопку, если её нет в разметке. На кнопке слева стрелка меню `Arrows/arrow-down-s-line`: вниз, пока блок закрыт, и вверх после поворота, когда открыт. Подпись меняется на `less`. Кегль подписи — `.text-xs`, младшая ступень шкалы `--text-xs`.

Список анализов собирает подблок в скрипте и вешает тот же плагин на `.dynblock-filters`: `more` — «Больше фильтров», `less` — «Меньше фильтров». Если в дополнительном поле уже есть значение, блок открыт. На этой панели кнопка не на границе: она в подвале сайдбара перед «Найти». Пока дополнительные поля закрыты, подвал сразу под основными. Когда открыты — подвал прижат к низу, список полей над ним скроллится.
