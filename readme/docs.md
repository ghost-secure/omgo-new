# Документы кабинета

Адрес `/manager/dokumenty/`. Страница каталога `mapurl = dokumenty`, php `web/docs.php`. Это список для пользователя, не справочник.

Справочник строк — другая страница, `/manager/admin/` → `mant_docs`, php `gen/t_docs.php`, грид `t_docs/base`. Её эта страница не заменяет.

## Как устроено

Типы вкладок — `t_docs_type` (`cat`, `varc_name`), порядок по `cat`. Сейчас это «Инструкции», «Бланки», «Документы». Строки — `t_docs`, в чужой тип не попадают: `view_type` равен `cat` типа. На тип не больше 100 строк, как лимит легаси-блока 52. Порядок строк — `cat`.

Вкладки — `UC\TabSet`. Открыта первая. В панели колонка карточек на всю ширину панели, без `width: 100%`: отступ карточки иначе вылезает за правый край. Строка карточки — `justify-between`: название и дата слева (`date_actual`, unix, формат `d.m.Y`), кнопки прижаты вправо:

- файл `doc_file` — «Открыть в браузере» (`target=_blank`) и «Скачать на компьютер» (`download`);
- ролик `varc_videourl` — зелёная кнопка «Просмотр видеоматериала», окно `data-plugin="window"` с `<video>`.

Пустого файла или ролика на карточке нет соответствующей кнопки. Адрес берётся только если это путь сайта, с `/` и без `//`. Поле `multiselect_roles` список не режет: в легаси `docs.php` фильтра по роли не было, условие было только `view_type`.

Данные собирает `DocumentService::sections()`. Отдельного шаблона динблока нет: разметка карточки одна на все типы и лежит в `web/docs.php`.

## История логики

### 2026-10-20 — строка документа внутри панели вкладок

- **Тип:** правка неверной логики
- **Было:** у карточки `w-full` (`width: 100%`) вместе с `p-md`. Общего `border-box` нет, отступ добавлялся снаружи и строка уходила за правый край вкладок
- **Стало:** ширина карточки по панели (`min-w-0 max-w-full _box`), без `width: 100%`

### 2026-10-20 — кнопки карточки справа

- **Тип:** правка неверной логики
- **Было:** на карточке стоял класс `justify-content-between`, его в наборе нет, кнопки оставались сразу за текстом
- **Стало:** `justify-between`, название слева, кнопки у правого края

### 2026-10-20 — список документов на вкладках

- **Тип:** новая логика
- **Было:** `web/docs.php` в каталоге, файла в проекте не было; легаси рисовал `uk-tab` и блок `tbldynelements` 52
- **Стало:** вкладки `UC\TabSet`, карточки `t_docs` из `DocumentService`
